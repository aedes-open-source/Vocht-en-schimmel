# Bijdragen

In deze map staan de bijdragen van corporaties: analyses, scripts en notebooks. Elke bijdrage krijgt een eigen map met de volgende structuur:

```
bijdragen/
  JJJJ-MM-naam-onderwerp/
    README.md          ← Wat onderzocht, methode, conclusie
    analyse.py         ← De code
    requirements.txt   ← Benodigde packages
```

Zet nooit databestanden in je bijdrage. Lees de [CONTRIBUTING.md](../CONTRIBUTING.md) voor de volledige uitleg.
