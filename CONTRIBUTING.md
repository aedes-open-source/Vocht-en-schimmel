# Bijdragen aan Vocht en Schimmel

Bedankt voor je interesse om bij te dragen aan dit project! Hieronder vind je een uitleg over hoe je kunt meedoen.

> **Let op: deel NOOIT ruwe data.**
>
> Geen adressen, geen woningnummers, geen herleidbare persoonsgegevens, geen CSV-bestanden met woningdata. Dit geldt voor de repository, voor Discussions, en voor Issues.

### Wat mag je wel delen?

- Geaggregeerde statistieken (gemiddelden, medianen, spreiding)
- Coefficienten, p-waardes, confusion matrices
- Feature importance scores
- Methodebeschrijvingen en conclusies
- Code en scripts (zonder data en linkjes naar sharepoints etc.)

## Hoe kun je meedoen?

### 1. Discussions — inhoudelijke discussie

Gebruik [Discussions](../../discussions) om:

- Een nieuwe indicator voor te stellen en te bespreken
- Je analyse-resultaten te delen
- Databronnen te delen die openbaar beschikbaar zijn
- Vragen te stellen over methodologie of aanpak
- Ideeen te delen voor het project

Kies de juiste categorie:

- **Indicatoren & Analyses** — voor alles over mogelijke variabelen die een verband hebben met schimmel en hun significantie
- **Modellering** — voor discussie over het voorspelmodel (ML-aanpak, validatie, etc.)
- **Hulp & Vragen** — voor vragen over methodes en technische vragen

### 2. Issues — verbeteringen aan de repository

Gebruik [Issues](../../issues) voor:

- Bugs in bestaande code
- Verbetervoorstellen voor code of documentatie
- Concrete taken die opgepakt moeten worden

### 3. Pull Requests — code bijdragen

Wil je code, analyses of notebooks bijdragen? Dat kan via een Pull Request:

1. Fork deze repository
2. Maak een nieuwe branch aan
3. Plaats je bijdrage in de map `bijdragen/` met de volgende structuur:

```
bijdragen/
  JJJJ-MM-naam-onderwerp/
    README.md          ← Wat onderzocht, methode, conclusie
    analyse.py         ← De code
    requirements.txt   ← Benodigde packages
```

4. Open een Pull Request met een duidelijke beschrijving

### Code-conventies

- **Dependencies:** vermeld alle benodigde packages in een `requirements.txt`
- **Geen data:** zet nooit databestanden in je bijdrage

## Vragen?

Open een Discussion in de categorie **Hulp & Vragen**, of maak een Issue aan.
